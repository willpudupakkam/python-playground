<a name="thread" /><p><b>thread:</b> To add pointers to link tree nodes together in some order</p>
<a name="Transpose" /><p><b>Transpose:</b> A heuristic in which the data item that is found is swapped with the data item before it in the list</p>
<a name="tree" /><p><b>tree:</b> A way of structuring data items in a hierarchical fashion</p>
<a name="treenode" /><p><b>tree node:</b> A part of a tree (not to be confused with a linked node)</p>
<a name="treetraversal" /><p><b>tree traversal:</b> The order in which the nodes of a tree are visited</p>
<a name="trie" /><p><b>trie:</b> An implementation storing strings in a tree structure</p>
<a name="U" /><h2>U</h2>
<a name="underflow" /><p><b>underflow:</b> When there are too few data items in a node in a (2,3) tree</p>
<a name="undirectedgraph" /><p><b>undirected graph:</b> A graph in which there is no distinction, or order, between the endpoints of an edge</p>
<a name="uniformdistribution" /><p><b>uniform distribution:</b> A probability distribution in which all probabilities are equal</p>
<a name="unorderedarray" /><p><b>unordered array:</b> An array in which data items do not necessarily appear in sorted order</p>
<a name="unorderedlinkedlist" /><p><b>unordered linked list:</b> A linked list in which data items do not necessarily appear in sorted order</p>
<a name="unorderedtree" /><p><b>unordered tree:</b> A tree in which the order of siblings does not matter</p>
<a name="unsuccessfulsearch" /><p><b>unsuccessful search:</b> A search that results in the data item not being found</p>
<a name="uptree" /><p><b>uptree:</b> An implementation for a tree using a single pointer to the parent of a node</p>
<a name="user" /><p><b>user:</b> In CS 234, the user of an ADT</p>
<a name="V" /><h2>V</h2>
<a name="vertex" /><p><b>vertex:</b> A part of a graph</p>
<a name="vertices" /><p><b>vertices:</b> Plural of vertex</p>
<a name="W" /><h2>W</h2>
<a name="worstcase" /><p><b>worst case:</b> A calculation of running time in which the representative value for each instance size k is determined by taking the maximum running time of any instance of that size</p>
<a name="Other" /><h2>Other</h2>
<a name="(2,3)tree" /><p><b>(2,3) tree:</b> A generalization of a binary search tree with one or two keys in each node</p>
